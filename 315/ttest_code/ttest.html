Preparation for a plot to help understand/comprehend the different scales of the standard deviations versus the standard error. The standard deviation estimates the standard deviation of the population of interest. The standard error estimates the standard deviation of the distribution of theoretical means.

dfs <- df %>%
  summarise(m = mean(Weight),
            s = sd(Weight),
            n = n(),
            se = s / n,
            t = qt(0.95, n - 1),
            p_lb = m - t * s, # if pop is roughly normal
            p_ub = m + t * s,
            m_lb = m - t * se, # pop not necessarily normal
            m_ub = m + t * se)

Notice the standard error is on a much smaller scale, since it is scaled by the square root of the number of data, namely the sample size \(n\). As the sample size increases, the standard error decreases. As the sample size decreases, the standard error increases.

ggplot(df) +

  geom_linerange(data = dfs, aes(x = 1.5, ymin = p_lb, ymax = p_ub)) +
